# RAG 工程化与运维

本子目录承接 RAG 专题的工程化与运维视角，关注"系统跑起来之后"的问题：知识库如何持续更新、线上系统如何被观测、成本如何被控制、安全边界如何被保护。

## 1. 子目录定位

本目录不重复讲解 Chunking、召回、重排等算法细节，这些内容由 [03-核心配置与实战](../03-核心配置与实战/) 与 [04-高阶与调优](../04-高阶与调优/) 承担。

本目录关注的核心问题包括：

- 文档源频繁变化时，知识库如何低成本同步
- 线上系统的命中率、引用率、延迟与成本如何被持续观测
- 如何通过缓存降低重复请求的成本与延迟
- RAG 系统面临哪些安全风险，如何在工程上防护
