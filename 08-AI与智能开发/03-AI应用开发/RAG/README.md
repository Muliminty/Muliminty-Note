# RAG 专题目录说明

本专题用于承载 RAG（Retrieval-Augmented Generation，检索增强生成）相关内容的系统化文章、阅读路径与工程化实践沉淀。

## 1. 专题定位

本专题聚焦三个层面：

- RAG 的基础概念与系统认知
- RAG 的核心实现链路与关键配置
- RAG 的高阶优化、评测与工程化方法

本专题**不重复承担最小基础认知入口**。如果你第一次接触 RAG，建议先从上游基础文进入，再回到专题树做系统展开。

## 2. 阅读起点与推荐顺序

建议按下面顺序阅读：

1. 先看 [RAG 原理](../../01-AI基础理论/05-RAG%20原理.md)，建立最小认知入口。
2. 再看 [什么是 RAG，它主要解决了什么问题](./01-概念与原理/01-什么是RAG，它主要解决了什么问题.md)，进入专题语境下的正式展开。
3. 接着看 [RAG 的完整链路与系统工作流程](./01-概念与原理/02-RAG%20的完整链路与系统工作流程.md)，建立全链路视角。
4. 然后进入 [RAG 知识库的构建流程](./02-快速上手/01-RAG%20知识库的构建流程.md) 与 Chunking、召回、重排等核心实战主题。
5. 最后阅读 Query Rewrite 与评测相关文章，形成优化闭环认知。

## 4. 各子目录说明

- `01-概念与原理`：解决“RAG 是什么、整体怎么运作、和哪些相邻概念有关”
- `02-快速上手`：解决“如果要开始落地，知识库应该怎么建”
- `03-核心配置与实战`：解决“Chunking、召回、重排这些核心环节具体怎么理解和怎么选型”
- `04-高阶与调优`：解决“当系统进入真实业务后，如何提升命中率、稳定性与评测能力”
- `05-工程化与运维`：解决“系统跑起来之后，如何持续更新、观测、控本与防护”
- `06-问题排错`：收纳真实踩坑场景的复现、归因与修复
- `99-参考与归档`：收纳写作 backlog 与后续非正文参考资料
