# Hono · 快速上手

本目录承载 Hono 的入门路径：环境准备、首个项目、最小可运行示例与项目模板。

## 目录角色

- 让读者在 **30 分钟内** 跑通第一个 Hono 应用
- 不展开核心机制原理（属于 [../03-核心机制/](../03-核心机制/)）
- 不涉及部署细节（属于 [../04-运行时与部署/](../04-运行时与部署/)）

## 规划文件

```
02-快速上手/
├── README.md                     ← 你在这里
├── 01-环境准备与选型.md          ← Node.js / Bun / Deno / Workers 任选其一
├── 02-第一个 Hono 应用.md        ← Hello World，路由 + JSON 返回
├── 03-项目结构与脚手架.md        ← create-hono 与目录约定
└── 04-开发调试与热更新.md        ← dev server、日志、调试技巧
```
