# Hono · 参考与归档

本目录是 Hono 专题的**保留区**，统一收纳历史草稿、网页剪藏、旧版笔记与外部参考资料。

## 目录角色

- 不参与正式阅读路径
- 不承担主题入口职责
- 默认**不参与站点发布**（受全局 Quartz 忽略规则约束）

## 收纳范围

- Hono 历史版本（v3 及以前）的旧笔记
- 官方博客 / 社区文章的剪藏
- 临时草稿、未完成的探索性笔记
- 已被新版正文替代但仍有参考价值的旧文

## 维护说明

- 文件命名保留原始信息，**不强制**按正文模板重写
- 若旧文中存在仍有效的知识，应在正式正文中以链接方式引用，而不是把归档页提升为主入口
- 凡是被正式正文完全覆盖的旧文，可直接删除，无需长期保留
