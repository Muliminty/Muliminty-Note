# Hono · 常见问题与排错

本目录收纳 Hono 使用过程中的**真实踩坑记录、根因分析与修复方案**。

## 目录角色

- 每篇正文聚焦**一个具体问题**，使用问题排错类模板
- 必须包含：现象 / 复现步骤 / 根因 / 修复方案 / 关联知识
- 不收纳泛泛的"使用技巧"（属于 [../05-高阶实战/](../05-高阶实战/)）

## 规划文件

```
07-常见问题与排错/
├── README.md                                 ← 你在这里
├── 01-Cloudflare Workers 部署常见报错.md
├── 02-Node.js 适配器与 Stream 兼容.md
├── 03-中间件执行顺序与洋葱模型陷阱.md
├── 04-类型推断丢失与 RPC 报错.md
└── 05-CORS / Cookie / SameSite 跨域问题.md
```

## 维护说明

- 新增排错记录 → 使用**问题排错类模板**
- 文件命名建议：`[序号]-[场景关键词]-[问题简述].md`
- 同类问题可合并为一篇，使用小节区分
