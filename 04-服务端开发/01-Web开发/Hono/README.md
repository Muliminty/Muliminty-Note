# Hono 目录说明

本目录承载 Hono Web 框架的学习笔记，覆盖从概念到实战的完整知识路径。

## 目录结构

```
Hono/
├── README.md                  ← 你在这里
├── 01-Hono框架概述.md          ← 框架概念、定位、架构总览
├── 02-快速上手/                ← 环境搭建、第一个项目
├── 03-核心机制/                ← 路由、中间件、Context、校验
├── 04-运行时与部署/            ← 多运行时适配、部署方案
├── 05-高阶实战/                ← RPC、JSX、测试、最佳实践
├── 06-生态与扩展/              ← 中间件生态、三方集成
├── 07-常见问题与排错/          ← 踩坑记录与解决方案
└── 99-参考与归档/              ← 历史资料、旧版笔记
```

## 阅读顺序建议

1. 先读 [01-Hono框架概述.md](./01-Hono框架概述.md)，建立全局认知
2. 按编号顺序逐步深入
3. 遇到具体问题跳转到 `07-常见问题与排错`

## 维护说明

- 新增概念知识 → 放入 `03-核心机制`，使用概念理解类模板
- 新增代码实战 → 放入 `05-高阶实战`，使用实战应用类模板
- 新增踩坑记录 → 放入 `07-常见问题与排错`，使用问题排错类模板
