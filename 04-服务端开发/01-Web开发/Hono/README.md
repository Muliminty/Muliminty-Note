# Hono 目录说明

本目录承载 Hono Web 框架的学习笔记，覆盖从概念到实战的完整知识路径。

## 目录结构

```
Hono/
├── README.md                  ← 你在这里（目录说明）
├── !MOC-Hono.md               ← 主题导航（推荐阅读路径与主题地图）
├── 01-Hono框架概述.md          ← 框架概念、定位、架构总览
├── 02-快速上手/                ← 环境搭建、第一个项目
├── 03-核心机制/                ← 路由、中间件、Context、校验
├── 04-运行时与部署/            ← 多运行时适配、部署方案
├── 05-高阶实战/                ← RPC、JSX、测试、最佳实践
├── 06-生态与扩展/              ← 官方中间件、第三方集成
├── 07-常见问题与排错/          ← 踩坑记录与解决方案
└── 99-参考与归档/              ← 历史资料、旧版笔记（不参与发布）
```

> 文件职责边界遵循 [02-百科组织规范.md](../../../99-系统/02-百科组织规范.md)：`README.md` 解释「目录怎么用」，[!MOC-Hono.md](./!MOC-Hono.md) 解释「主题先看什么」。

## 阅读顺序建议

1. 先读 [01-Hono框架概述.md](./01-Hono框架概述.md)，建立全局认知
2. 跟随 [!MOC-Hono.md](./!MOC-Hono.md) 的推荐路径逐步深入
3. 遇到具体问题跳转到 [07-常见问题与排错](./07-常见问题与排错/)
