# Hono · 核心机制

本目录解释 Hono 的**核心运行机制**——路由、中间件、Context、校验器、错误处理等运行时模型。

## 目录角色

- 承载概念性知识，回答「Hono 是怎么工作的」
- 每篇正文聚焦**一个核心机制**，使用概念理解类模板
- 不承担可运行示例（属于 [../02-快速上手/](../02-快速上手/) 或 [../05-高阶实战/](../05-高阶实战/)）

## 规划文件

```
03-核心机制/
├── README.md                       ← 你在这里
├── 01-路由系统与 RegExpRouter.md   ← Trie/正则路由匹配原理
├── 02-中间件与洋葱模型.md          ← Koa 风格中间件链
├── 03-Context 对象详解.md          ← c.req / c.res / c.env / c.var
├── 04-请求解析与响应构造.md        ← parseBody / json / html / stream
├── 05-校验器与类型推断.md          ← @hono/zod-validator + 类型派生
├── 06-错误处理与 onError.md        ← HTTPException 与全局错误
└── 07-应用嵌套与子路由.md          ← app.route() 与 basePath
```
