# Recoil

`Recoil` 是一个面向 React 的状态管理库，以原子状态和选择器为核心，强调细粒度依赖更新。

## 是什么

`Recoil` 将共享状态拆成多个独立的 `atom`，组件按需订阅自己关心的状态片段；在此基础上，再通过 `selector` 组合、计算和派生出新的状态值。

可以把它理解为：

- `atom`：最小可订阅状态单元
- `selector`：基于状态计算出的派生值
- 组件：只在依赖的状态发生变化时更新

## 核心特点

- 原子化状态拆分，避免把所有共享状态都堆进一个大对象
- 组件按依赖订阅状态，更新粒度更细
- 支持派生状态建模，适合表达计算结果和状态组合

## 适合场景

- 组件树较深
- 需要细粒度订阅和派生值
- 多个组件需要共享状态，但又不希望因为无关字段变化而频繁重渲染

## 使用提醒

- 适合处理 React 应用中的客户端共享状态
- 如果主要问题是服务端数据获取、缓存与同步，更应优先考虑 TanStack Query 一类方案
- 在当前生态中，`Recoil` 已不是新项目的默认优先选择，选型时通常也会一并评估 Zustand、Jotai 或 Redux Toolkit
