# Agent 核心组件速查

收纳 Agent 体系中常见关键词的最小定义，便于快速回忆与跳转扩展。

## 1. 四大核心组件

- **大脑**：LLM
- **规划（Planning）**：将复杂目标拆解为可执行子任务
- **记忆（Memory）**：跨轮上下文与长期偏好存储
- **工具（Tool Use）**：调用外部能力，例如搜索、代码解释器、API

## 2. 常见模式与框架

- **ReAct Loop**：思考 → 行动 → 观察的循环模式
- **LangGraph**：用图（Graph）结构管理复杂的 Agent 状态
- **Role Playing**：通过 Prompt 隔离不同 Agent 的职责
- **Handoffs**：任务在不同 Agent 之间的流转
- **Function Calling**：模型通过结构化输出调用外部函数
- **多 Agent 框架**：典型实现包括 CrewAI、AutoGen

## 3. 与 RAG 的关系

RAG 可以概括为「搜索引擎 + 大语言模型」：

- **R（检索）**：利用句向量充当 AI 的"眼睛"，找到外部最新、最私密的知识
- **G（生成）**：利用 Token 向量充当 AI 的"嘴巴"，把检索到的信息组织成回答

没有 RAG 的 LLM 更像一个"记性很好的空想家"；接入 RAG 后，模型才具备贴合业务的依据。
